# Public example sources and limits

These are independently drawn views of bounded frozen public results, not copied journal figures and not native-server acceptance. Exact exported PNG/SVG hashes remain in `visual_reviews.json`; numerical values/sample identities were not changed for publication. Only local file-location fields were replaced by artifact names. Public result reuse does not authorize uploading private project data.

| Display | Actual public source and attribution | Scope of this distribution |
| --- | --- | --- |
| Volcano | Himes et al. 2014, PLOS ONE 9:e99625, DOI https://doi.org/10.1371/journal.pone.0099625 ; public author DE results at GEO GSE52778, https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE52778 . The source article's Creative Commons Attribution notice is retained by this attribution. | Existing Cuffdiff gene effect/FDR table, not DESeq2 counts or a new DE fit. |
| Pathway matrix | Same GSE52778 expression source; frozen ssGSEA scores using Hallmark. | Row-Z scores over the sixteen actual samples. | Intervals/ranking | Wolberg, Mangasarian, Street and Street, UCI Breast Cancer Wisconsin (Diagnostic), https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic ; CC BY 4.0, DOI https://doi.org/10.24432/C5DW2B . | Frozen independent-observation bootstrap feature effects and supplied intervals. Educational public benchmark, not clinical validation. |
| Detection proportions | 10x Genomics PBMC3k, https://www.10xgenomics.com/datasets/3-k-pbm-cs-from-a-healthy-donor-1-standard-1-1-0 (CC BY 4.0); processed object from https://github.com/chanzuckerberg/cellxgene/blob/main/example-dataset/pbmc3k.h5ad . | Existing IL7R fractions from nonnegative raw-layer expression; eight supplied cell identities, one donor. No invented donor comparison or scaled-value positivity. |
| Docking scatter | AutoDock Vina official 1IEP example, https://github.com/ccsb-scripps/AutoDock-Vina/tree/develop/example/basic_docking/solution ; Apache-2.0. | Four already-computed dependent poses and score/RMSD channels; no crystal pose relabeled as docking and no experimental affinity claim. |

The maintained rendering code is licensed separately from these public data sources. Upstream notices below are retained for relevant tutorial/example-derived material; no model, complete database, raw trajectory, full expression matrix, raw single-cell object, article PDF or original paper figure is redistributed. Source-specific restrictions are not replaced by the workbench license.
