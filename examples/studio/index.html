使用 Figure Studio

  1. 在左侧搜索可执行绘图器或查看完整历史图例。
  2. 导入已有 SVG 和对应 FigureSpec，可比较字体与字号预览。
  3. 导出重绘配置，用 workbench.py plan / render 生成正式 PDF、SVG、PNG、表格及来源记录。
  4. 实际检查最终大小的导出，再单独记录视觉验收。

未载入 FigureSpec 时，只导出外观设置，页面不会猜测原数据和绘图参数。浏览器字体预览不保证目标机器存在该字体。文件不会上传；页面不启动服务器。
