# 图册去重与稳定导航

完整包的入口现为[综合绘图库](../assets/visual-library/index.html)：跨19份现有图库，保留90个基础画法、458个历史示例及全部已有方法，按83个父族选择具名扩展。三维、雷达不受历史／替代选项隐藏。下文的550／103仅描述转录组分析子目录；按渲染器分组仍会跨入口重复，不能当作整个包的最终去重统计。综合目录按明确的画法映射跨入口归组，原始模式、分析用途和文件均保留；[生成的覆盖清单](visual-library-coverage.md)给出精确范围。

图册提供两个用途明确的入口：默认“按画法去重”，以及“按分析问题阅读”。

## 合并的对象

- 同一渲染器的同一种画法收成一个可复用画法族。相同面板集合的行列与顺序变化收为布局扩展。
- 热图、比例图、效应区间、云雨图等不因换一组示例数据或标题就成为新画法。分析示例在画法内选择，保留各自的单位、分母、估计量、范围和准确下载文件。
- 专门的 PCA、完整 GSEA、带层次树的 TOM、逐亚群多 marker 等保留不同的信息结构。仅因都有矩阵，不能把 TOM 层次证据与一般热图当成完全相同的图。
- “按分析问题阅读”保留互补的设计、QC、主结果、功能和验证问题；明确命名的布局／替代版与确切相同的内容别名折叠到原条目。

## 稳定性

章节顺序来自固定目录；画法族 ID 来自渲染器与面板结构，和标题、数据量无关。搜索匹配具体示例时只展示该匹配示例。切换浏览方式或扩展选项时保留当前图；主动改变分析筛选后只显示该分析的示例。所有550个原始图 ID 继续可达，常规图册旧数字链接继续映射原图。

HTML 导航重新生成不修改原 PNG、SVG、PDF、TSV 或图片审阅哈希。原有前版切换功能保留。新输入、新布局和新导出仍须逐张审阅。

## 实际结果去重

模板家族合并与结果去重分开。版本2的 study bundle 只在冻结输入、参数、主题、输出设置、来源与调用方研究范围全部一致时折叠重复导出，并留下别名记录。不同细胞类型、供体单位、队列、对比或分母不能因数字恰好相同而合并。书籍清单只接入已明确提供的结果；不把图库中独立的虚构模板拼接成一项研究。
