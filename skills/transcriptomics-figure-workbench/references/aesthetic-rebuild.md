# 重构后的视觉语法与补充画法

这一轮是 **v0.3.0 视觉重构**。原先八张软件接口样例的美观验收未通过；它们保留为机械测试。不要把软件成功、这轮自检或合成示例当作真实研究的验收。

[打开12张可放大的实际预览](../assets/aesthetic-gallery/index.html)。A01–A06 是重新设计的既有画法；B01–B06 是补充入口。每张均有 SVG/PDF/PNG、准确表格、来源、参数及重绘配置。页面可以筛选并保存逐图意见；意见留在当前浏览器，可导出 JSON。260 个历史来源编号及原意见键继续保留。

## 重画的六种表达

| 编号 | 画法 | 设计与边界 |
|---|---|---|
| A01 | 火山图 | 紧凑图例、分开的正负语义色、较弱的背景点；输入已计算的效应与调整后 P；显示阈值不重新执行差异分析 |
| A02 | 森林图 | 标签、区间及数字三列对齐；移除碎片底纹，所有正文用深色；只显示已有区间，必须声明效应尺度 |
| A03 | 配对变化 | 轻连接线、完整个体点；每对共用少量横向偏移以减少遮挡，Y 值完全不动；密集时要求分面 |
| A04 | ROC | 原有阈值顺序的阶梯曲线、线型加颜色、图外图例；两轴单调性检查，不估计 AUC 或阈值 |
| A05 | 排名轨迹 | 整数名次刻度、直接末端标签、点形区分；保留已有名次；末端并列需另选分面 |
| A06 | 连续矩阵 | 根据行列数调整尺寸、完整身份标签、较窄色条；必须给出共同色域，越界不静默裁剪 |

统一入口为 `editorial`，`kind` 选择上述模式。详细参数来自自动生成的 renderer directory。新的 `contract` 要求来源、独立单位、分母、量值定义、区间定义以及 synthetic 布尔值。该值必须与导出来源记录一致。

## 六个补充入口

| 编号 / 别名 | 需要的数据 | 能表达什么 | 限制 |
|---|---|---|---|
| B01 / `mosaic_counts` | group、category、非负整数 count；完整列联格 | 组宽代表该组总数，组内高度代表比例，面积对应总量中的份额 | 缺格不等于零；每组分母必须为正；不做列联检验或组间推断 |
| B02 / `waffle_counts` | 每个 category 一个非负整数 count；unit_label | 每格准确代表一个已声明单位；显示规模与组成 | 总量1–400，不把连续比例或大数量凑整成100格；零类别仍在图例 |
| B03 / `horizon_series` | series、已有有序 x、已有有符号 value；显式 band_width/bands | 紧凑比较多条时间序列的方向与幅度 | 必须保留同值的普通线性参照；越界阻断；只在原点之间连直线，不平滑或拟合 |
| B04 / `connected_scatter` | series、递增 step、同一步对应的 x/y；两轴单位 | 两种指标随已有时间顺序的共同变化 | 空心点为起点，标出起末步骤；连线不是推断轨迹或因果路径 |
| B05 / `mirrored_bars` | category、恰好两个 group、非负 value；unit_label | 同类对象两组规模的直接对照 | 共用零点及对称尺度；左侧是镜像的非负量，不代表负效应；缺格阻断 |
| B06 / `genomic_rainfall` | 唯一 variant_id、chromosome、1-based position、上游给定正整数 gap、group；assembly/gap_definition | 基因组事件间距与局部密集区域的描述 | 每条染色体单独位置轴，共用间距 log 轴；不跨染色体计算间距，不识别突变热点，不做签名分析 |

这些是补充绘图入口；不能直接相加称为新的科学算法。连线、镜像和方格与既有语法有联系。历史主目录的去重统计和本轮补充样例分别记录。

## 外观与验收

- 继续使用项目主题：固定类别颜色、连续量的色域/中心、字体及字号层级。这里的 C10 是演示选择，不能代替用户课题色卡。
- 默认使用白底、深色正文、轻网格，独立安排图例和色条。实际导出尺寸必须检查；不能只看缩略图或让大标题掩盖稀疏数据。
- 新模板绘制完成后检查文字越界及文字之间的遮挡，发现问题时阻断导出。这个几何门禁不判断审美、颜色辨识或科研有效性，也不能涵盖所有文字与数据图元的遮挡。
- 随后的全图谱升级覆盖400个实际导出（含全部历史主图、辅助图和排版变体），已逐张检查PNG。PDF结构检查与PNG视觉检查分开记录，详见 [全图谱自检](full-atlas-review.md)。
- 正式使用时由项目 FigureSpec 绑定实际来源、单位、对照、分母及区间定义。图上条目不自动成为独立生物学重复。上游分析继续在既有服务器运行。
