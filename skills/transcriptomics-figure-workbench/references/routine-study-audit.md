# 普通常规指令的完整模拟出图检查

这一轮使用同一套明确虚构的结果：12 个供体、每条件 6 个供体、900 个嵌套细胞、1,200 个差异结果基因，5 个身份各 4 个 marker。全部为软件绘图材料，未运行 RNA-seq 分析引擎，也没有真实研究结论。

## 普通指令与选择

实际使用 `study-plan` 处理“帮我把这套 bulk 结果画成整套图”“帮我把这套单细胞结果画成整套图”“画质控图”“展示差异和通路”“展示各个亚群的 marker”。这是对显式结果清单的有界路由；不能自动查找私人文件，也不能推断尚未提供的科学结果。

- **Bulk 15 份默认图：** 总览、表达 QC 云雨、PCA、相关性、文库覆盖、设计矩阵、堆积火山、表达程序热图、效应区间森林、MA、逐供体基因云雨、ORA、三通路 GSEA、NES 摘要、基因—通路支持。
- **单细胞 23 份默认图：** 三项 QC 云雨、供体覆盖、批次分面、设计矩阵、身份与 marker 总览、20-marker 点阵、五个代表 marker、5 份逐亚群四-marker 页、条件分面、逐供体组成、细胞数支持，以及明确限定 Myeloid 的供体级差异、森林、热图、MA、ORA、GSEA、NES 摘要与基因支持。
- **5 份阅读/自定义伴随图：** Bulk 与 Myeloid 单通路 GSEA、两列 marker 块、三列整页亚群布局、横排三通路 GSEA。

单细胞差异结果在这个软件样例里有意复用同一份虚构差异数值，不代表做了两项独立科学分析。没有其他细胞类型的差异推断，也没有以这 43 份图宣称覆盖全部组学分析。已有 58 章节与条件性扩展继续保留。

## 这轮改到实现里的问题

| 问题 | 当前实现 |
|---|---|
| 逐基因和 QC 默认仍是箱线叠点 | 有冻结密度时优先云雨：半云、全部观测点、窄箱体/中位数。明确基因数、细胞数和独立供体数，保留小样本的每个点 |
| 森林图留白过大、阅读分散 | 基因名、区间图、精确数值三列对齐；高度随条目数调整，轻底纹、圆端区间、明确对比 |
| 热图侧边注释离开矩阵 | 注释紧贴矩阵，标签移至注释外侧，顺序和原始数值保留 |
| 三通路 GSEA 被自动拉成狭长页 | 内部轨道由 GSEA 布局管理；默认平衡分面，另给单通路和显式横排阅读版 |
| 单对比 NES 摘要只排一列气泡 | 单对比直接以 NES 为横轴；跨对比仍使用对齐矩阵，保留 FDR、成员与效应的独立含义 |
| “每个亚群”只得到代表 marker | 清单支持同一 `marker_subgroup` 角色的多个明确身份，每页独立 id、focus_group 和完整 marker 列表 |
| 条件分面和计数标签不一致 | 固定身份顺序及完整坐标范围，细胞数/设计值按整数显示 |
| 图间模拟数字不一致 | marker 均值/比例绑定同一表达，GSEA 命中/增量/leading-edge 一致，ORA 与总览使用相同查询分母 |

云层为预先准备并冻结的显示形状，不在绘图阶段重新估计 KDE。逐基因示例固定带宽为 0.20 个显示单位；QC 分别使用明确记录的显示带宽。每组 6 个供体的云层不能证明稳定的总体分布，点与样本量必须保留。QC 的每样本 180 基因是这个质控样例的输入范围，不是 1,200 个差异结果基因的重新筛选。

## 复现与自检边界

图册每图含 PNG、SVG、PDF、冻结 TSV 和 `figure.spec.json`，两套普通请求清单可以直接用于 `study-plan`。仓库的 `tools/build_routine_study_audit.py` 准备全新模拟冻结输入，`tools/render_routine_study_audit.py` 串行绘制普通请求及 5 份布局伴随图。不会下载真实数据或运行正式推断。

屏幕自检记录对应每张最终 PNG 的哈希，覆盖单图、组图与显式自定义布局。出现新导出后必须重新检查。未修改的图片可沿用本轮对同一字节的实际查看记录。渲染器回执仍保留 `RENDERED_UNREVIEWED`，独立的屏幕记录不会伪装成后端科学验收。

这次没有独立审美评审、纸面印刷校样或科学方法验收。屏幕自检说明实际看过、修过并核对了当前数据与尺寸，不能保证新数据、新标签或缩小后的期刊栏宽仍然合适。
