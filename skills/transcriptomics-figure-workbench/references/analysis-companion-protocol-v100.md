# 按分析问题选择完整配套画法

## 每个章节应交付什么

已有主图继续承担该分析最核心的问题；配套页分别回答输入支持、诊断、效应与不确定性、功能解释及复现/敏感性问题。不能用一张总览图代替这些问题，也不能把几张近似矩阵计作几种新分析。逐项路线见 [章节清单](analysis-companion-coverage-v100.md)，实际图和冻结输入见 [完整示例](../assets/companion-gallery/index.html)。

按研究问题和真实返回的结果选择所需章节。剪接、融合、生存、轨迹、velocity、空间、VDJ、Perturb-seq、多组学等都有各自的数据与设计前提，不能因模板存在就强加给每套转录组。完整绘图路线不等于运行了这些分析，也不保证某个研究已经拥有所有结果。

此配套库的各题示例是独立的绘图测试材料，不能将不同题目的示例数值拼成同一队列的科学结果。组图用于检验不同信息通道的排布。需要从同一套虚构结果按常规指令取图时，另见原有 routine/study 示例；真实项目必须绑定同一输入、对比与来源版本。

## 推荐的阅读顺序

1. **输入和 QC：** 独立供体、嵌套文库/细胞、完整分类分母、检出覆盖、参考版本、缺失和混杂。
2. **主结果：** 继续使用已有专用主图，例如 PCA 分布与边际、火山/MA 边际、完整 GSEA、每亚群多 marker、网络与物理基因座。
3. **解释与支持：** 命中/leading edge/成员、供体层面表达或评分、效应与原始供给的区间、配体/受体或 TF/靶基因支持。
4. **诊断和验证：** 拟合诊断、预先指定的模型/参数/参考选择对比、独立队列。相同供体的替代模型不能冒充独立复现。
5. **版式：** 单页、平衡组图、扩展数据的一列阅读版；合适的章节另有三列宽版。保留行列/物理宽度的显式请求，重新导出后重新审图。

## 输入语义与画法合同

|画法|必须供给|审查重点|
|---|---|---|
|冻结曲线/带状范围|series、x、y，可选 lower/upper 及范围定义|不拟合/平滑；阴影有可见说明；生存概率不可上升；测序碱基比例逐位置合计为 1|
|观测散点|x/y、分组、点所代表的单位|基因/细胞/邻域不是供体；只有同量纲的一致性问题才画恒等线|
|效应和对齐表|明确估计量、上下界和区间定义；可选 q、检验族及有效独立 n|不由 SE 临时制造区间；ratio 用对数轴和零效应 1；差值参考 0；概率/比例的范围符合定义|
|云雨图|逐独立单位数值、分组、每组明确供给的云形坐标和定义|保留每个点和 n；云形不是临时 KDE；重复单位改用配对图；小样本不隐藏原始点|
|配对图|同一单位在两个条件下的数值|只连接相同单位；显示配对数；不能把不同供体按顺序连起来|
|矩阵|完整行/列标识、量纲、明确零/非成员与数值范围|保持全量选择；计数为整数、二值成员为 0/1；完整方差组成含残差且逐行合计为 1；不混同不同方法的评分|
|比例和分母|每对象所有类别、比例、明确总数和分母定义|合计为 1；total 是读段/细胞/特征总数时不标作独立 n；过滤前后来自同一特征全集|
|冻结分箱|每组每箱起止位置和数量，包括空箱|连续且不重叠；画浅填色和清晰轮廓，避免重叠后只剩灰块；不在绘图中重新分箱|
|物理基因座|参考版本、contig、链、0-based half-open 区间、外显子/连接/峰/关联及其定义|物理长度不等于网络距离；保留 junction 数或非因果 peak–gene 权重；不能将位置图当作结构/功能证实|

并非所有分析软件都会提供置信区间。比如常规 fgsea 的 NES 表通常不带 NES 区间：没有上游区间时选已有 NES/ES 专用主图，不能为了套用效应图补造区间。这里的合成区间只是明确给定的绘图通道，不是通过这些示例验证的置信区间。

## 兼容入口

`analysis-library --search <问题或章节>` 查找；`analysis-suite --chapter <id> --output <fresh-directory>` 导出整套默认模板、实际冻结 TSV 和 manifest。加 `--include-variants` 才加入相近替代、组合和布局，避免默认重复输出。`analysis-render --manifest <directory>/manifest.json --output <fresh-render-directory>` 串行绘制示例。

真实研究先检查原有分析/QC 回执，再按结果通道替换 TSV、更新输入哈希、方法/独立单位/选择范围与物理尺寸，走 `plan` → `render` → 逐张查看。整个章节打包的模板不是服务器计算回执，也不能替代统计咨询。

## 布局和审美验收

一页只承担一个主要问题。单张图可读，才组合成有清楚阅读顺序的组图。相近热图共用矩阵语法和参数扩展，仍保留不同分析的量纲与成员定义。表格、图例、色标各有位置；用增加行高、换行、阅读页或分页解决长标签，不能靠压小字体通过。

示例一列阅读版和三列宽版分别声明较大的物理宽度，不能声称缩成期刊单栏仍清楚。字级测量、数值/结构校验、逐图屏幕自检、纸面校样、独立审美评审和科学有效性是不同状态。修改结果、标签、选择、主题、尺寸、行列或代码后，旧图片的审阅结论不自动适用于新导出。

本版图形语法独立实现；原算法、数据库和外部软件保留作者归属。[方法和设计来源](analysis-companion-sources-v100.md) 记录采用的语义与没有照搬的部分。没有复制期刊图片、第三方分析脚本、模型权重或私有结果。
