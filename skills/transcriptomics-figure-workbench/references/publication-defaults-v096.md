## 选择规则

先确定研究问题、独立单位、分母、结果表及已有信息通道，再从实际完整示例选择。优先采用清楚且信息充分的画法。保留经典画法供明确需要简图的请求；不因为最简单的函数容易调用就默认使用。`study-plan` 记录优先形式、舍弃的基础方案和实际可用输入。规划状态不代表审美通过。

| 已有图组 | 常规优先形式 | 本轮舍弃或修复 |
| --- | --- | --- |
| Bulk 总览 | 四个完整主面板，详细结果另页阅读 | 热图图例与条件条相碰，已重新留位 |
| PCA | 全部样本、给定离散椭圆、两轴边缘比例、解释方差 | 只有裸点或用椭圆暗示统计分离 |
| 火山与 MA | 全部检测基因、完整堆积边缘、清楚阈值和方向 | 丢弃不显著基因或单独压缩显著性边缘造成比例失真 |
| QC | 按条件/指标分面，半云、全部观测点、窄箱、每样本计数 | 密集样本硬挤一行、只剩箱体；超过8个样本/条件时分块 |

| GSEA | 完整ES、精确命中、leading edge、排序指标、NES/FDR、集合版本 | 单曲线省略底部证据；单通路渐变线对比度不足，改为实色精确曲线+独立指标色带 |
| 文库/供体覆盖 | 逐单位数量、精确直接标签和条件 | 仅凭ID推断生物学独立性 |
| 设计 | 离散0/1指示与显式参考编码 | 为0/1类别使用连续色阶 |
| 细胞图谱 | 身份地图与20个marker跨群均值/检出率 | 地图脱离注释证据，基因名称与底部色标相碰 |
| Marker 点图 | 全部100个组合、分块名称、每群细胞数、共同均值色阶和面积定义 | 无类别名称的顶部色条 |
| 特征图 | 完整共同坐标和表达范围；少量marker连续阅读、多行由请求决定 | 固定网格、巨大色标、不同marker自行拉伸色阶 |
| 逐亚群 | 每群定位+跨全部群特异性+对应全部四marker图；直接注明检出率/均值 | 用全局单marker页代替；三列版本标签侵入定位图，已留专属标签区 |

## 实际检查范围

- 15份 bulk 默认图、23份单细胞默认图、5份单通路阅读/自定义布局，共43份最终PNG逐张屏幕自检。实际返修后的文件重新看图。每条记录绑定最终PNG哈希。
- 同一套虚构12供体、900细胞、1,200基因结果。43份输入TSV与v0.9.5逐字节相同；前版图片可在读图器切换查看。没有重算DE、FDR、富集、嵌入或不确定性。
- 另有六份有界扩展：4/24样本QC、两列细胞组成、两列特征图、12行效应表、单列四基因云雨。复制的虚构值只用于布局检查，不代表额外生物学重复或新的结果。
- `target_width_mm` 和字号门禁检查实际缩放；本组多面板示例采用180–297mm阅读宽度。自动字号检查不是纸面校样，不保证任意缩到单栏仍可读。
- 屏幕自检、输入一致性、导出结构检查、独立审美评审、纸面校样和科学分析验收分别记录。本轮没有独立审美评审、纸面校样或真实科学推断。

## 可复现与边界

每图保留可编辑SVG、PDF、完整PNG、冻结TSV和FigureSpec。通过普通 `plan` / `render` 入口重现；完整请求通过两套StudyFigureManifest规划。前后对照不依赖网络。

云形须由既有后端提供明确网格、宽度、观测数和定义。绘图器只验证范围、计数并绘制。仅合成样例准备工具可建立明确标注的固定带宽显示几何；不得对真实数据借此在本地拟合。

缺失分析结果仍然是缺失，不能用示意图填成真实发现。单细胞差异和通路示例只包含 Myeloid 供体级对比；其余身份只展示已有marker和组成。所有虚构效应、NES和FDR均非生物学证据。

新数据、标注、主题、顺序、尺寸或行列要求会使旧审阅失效。实际使用时必须重新检查完整单图和组图，不能直接沿用这49份导出的自检记录。
