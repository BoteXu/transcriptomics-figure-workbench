# 用数据结构与表达目的选图

目录首先回答“哪种数据适合这张图表达”。科研领域、物种、软件名与数据出处不作为主要图型分类。以下是选图索引；正式绘制时再记录实际数据、单位和统计语义。

| 数据形状 | 想表达什么 | 优先图型 | 需要避免的误读 |
|---|---|---|---|
| 每个对象一个数值＋组别 | 组间分布、离散与异常点 | 原始点、蜂群、箱线、已有密度的雨云 | 点是否为独立对象；均值图不能说明全部分布 |
| 每个对象 X、Y 两个连续数值 | 关联、趋势、离散和异常点 | 散点；需要分布信息时增加边缘分布 | 相关不等于一致、因果或预测准确 |
| X、Y＋第三个独立数值 | 三变量关系 | 气泡散点，面积编码第三值 | 面积与半径不能混用；图例注明大小语义 |
| 有序 X×系列×Y，可有区间 | 随时间、剂量、位置的变化 | 曲线＋已有区间带；多系列分面 | 无序分类不画成连续趋势；范围带不是自动置信区间 |
| 分类×组别×估计值/上下界 | 多条件比较 | 分组点区间；适合零基线的柱图 | 缺项不是零；SD、SE、CI 不能不加说明混用 |
| 每个项目效应、区间、标签 | 方向、幅度和不确定性 | 森林图 | 差值零线与比值一线不同；区间需来自上游 |
| 分类×组成项×计数或比例 | 构成及其变化 | 堆叠柱、组成点；少类别用环形图 | 分母必须可解释；精确组间比较优先位置编码 |
| 行类别×列类别×数值 | 模式、强弱和成块结构 | 热图、气泡矩阵 | 颜色范围与单位统一；已有层次树与矩阵顺序对应 |
| 变量对×关联系数，可有 p | 成对关系及方向 | 三角相关矩阵、椭圆矩阵 | 多重校正约定明确；不从颜色推机制 |
| 节点＋边＋方向/权重 | 连接模式和已知边属性 | 网络图或邻接矩阵 | 相关边不自动成为调控箭头；布局距离不是生物距离 |
| 对象×多个维度＋评价分数 | 配置之间的权衡 | 平行坐标 | 各轴尺度明示；曲线连接只是显示形式 |
| 对象×特征×已有贡献值＋特征值 | 对模型输出的贡献分布 | 贡献蜂群、分类分面 | 图只能展示上游解释量；不把贡献当成因果效应 |
| 对象×固定降维坐标＋组别 | 已有低维几何与组别分布 | 坐标散点、质心连线、提供的椭圆 | 不根据图重新计算或改动 embedding；椭圆定义需明确 |
| 重复运行×轮次×指标 | 算法过程、稳定性和诊断 | 曲线、运行热图与配套诊断 | 曲线好看不等于泛化；停止点来自已有规则 |
| 共用类别轴的多个计数/矩阵 | 多层指标之间的对照 | 对齐轨道＋矩阵 | 列顺序与层级对齐；各量纲色标独立明确 |
| 完整 X×Y 网格×Z | 现有曲面或地形 | 二维色块优先；空间几何必要时三维面 | 不从稀疏点虚构平滑曲面；遮挡限制需承认 |
| 经度/纬度＋数值或路径 | 地理场与已有流动关系 | 地图、区域图、路径图 | 投影、区域尺度及单位明确；路径不是推断迁移 |
| 对象＋步骤＋已有矩阵/评价/计数 | 流程与结果如何衔接 | 流程窗与独立结果 panel | 示意对象与真实结构分开标记；不把流程当证据 |
| 真实三维坐标＋链/残基选择 | 整体结构、表面和局部细节 | 丝带、表面、棒状局部图 | 仅凭截图不能重建原子结构；表面形状不能推出亲和力 |

审美参考中的环形、玫瑰、3D、复杂网络可保留为选择；它们不是默认“高级”。当坐标位置、简单区间或二维矩阵表达更清楚时，优先简单图。统计量是否合理应结合具体科研问题判断，图型目录不预设领域结论。

先读本索引选 family；需要精确单图 schema 时读 panel-patterns.json；需要复合排版对照时读 reference-patterns-20261005.md。课题统一样式读 project-style.md。每个 panel 分开调整并保留编号，最终组图也使用同一课题配置。
