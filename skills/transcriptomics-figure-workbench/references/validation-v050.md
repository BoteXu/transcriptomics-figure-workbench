# v0.5 inspection and acceptance scope

## Actual visual work

- Baseline: 400 atlas exports, 25 package examples and 8 legacy GSEA/ORA examples; 433 distinct active PNGs. Historical source PNGs are inventoried separately.
- All 49 contact plates were viewed (nine figures per plate except the last). This is an overview screen, not individual final-size approval.
- Individual full-image screen inspection: P01, K01, R01/R02/R03/R04/R07/R11/R16/R22, all PKG01–PKG25 and VIS01–VIS05; 40 current figures. Large images may be resized by the viewer. Original changed versions remain accessible.
- Five display repairs preserve source graphical primitives and table hashes: radial fill/colour, 28 label offsets, neutral nonsignificant edges and point opacity.
- Five alternative examples have actual PNG/PDF/SVG, plotted TSV, source bindings and FigureSpec. Half-eye outer/inner bounds are illustrative supplied constants, not estimated confidence/credible intervals.
- Five new examples were additionally viewed at nominal CSS 178 mm width. These screen views are not physically calibrated or paper proofs.
- No blanket final-size visual acceptance, native package execution, scientific acceptance or paper proof is claimed. PDF text baseline checks do not establish full glyph bounds or PNG/vector pixel parity.

## Physical-size screen

At 178 mm width, 139 of the 438 current exports have a body-font lower-decile screen below 7 pt. They remain flagged for reflow or a larger format. The screen excludes top/bottom page furniture, retains guides and superscripts, and is advisory. New renderer examples additionally check all declared essential text sizes against their specified 6.5 pt minimum; these two metrics have different scopes.

The offline review gallery distinguishes overview, individual screen review and size warnings. It provides standalone panel reading for 126 oversized or alternative compositions. A component reading edition is not a paper composition.

## Software gates

The release checks dependency-free design contracts, missing-channel/context HOLD, changed input hashes, physical-size parameter limits, five actual display routes, negative density/nonnested bounds/incomplete or inconsistent matrix channels, clipped scale limits, no mutation of input tables, size HOLD before bundle creation and artifact-bound review expiry. UI checks cover preferred examples, all 25 package selections, all 438 review entries, 139 size flags, 126 component routes, original/revised toggle, native zoom, narrow layouts and rejection of active/external SVG content.

Automated tests use injected review decisions only to test state handling; they do not create actual visual acceptance. Existing historical preservation and source/parameter checks remain required. Local test receipts and CI job status are separate from these documented acceptance criteria.

## References and adoption

The independently implemented displays draw on the design concepts documented in the [ggdist slab/interval guide](https://mjskay.github.io/ggdist/articles/slabinterval.html) and [ComplexHeatmap split guide](https://jokergoo.github.io/ComplexHeatmap-reference/book/a-single-heatmap.html#heatmap-split). See [the design contracts](design-workflow-v050.md) for scope and limitations. No new readable WeChat article was obtained; no unseen article code is claimed as integrated.
