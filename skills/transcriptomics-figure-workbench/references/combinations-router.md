# 组合形式与数据匹配

20个K组合已有实际独立组件和组合导出，组件表不合并成一个虚构数据集。旧版P和R中的组合也完整保留。横排、纵排与网格是排版参数；改变排版不新增图型。

| 预览 | 组合 | 必要输入／对应关系 | 表达 |
|---|---|---|---|
| K01 | 分类坐标＋特征矩阵 | 对象坐标与类别＋类别×特征值 | 看位置和概括特征 |
| K02 | 分类坐标＋同位置连续特征分面 | 同对象ID和同一XY的多个特征 | 位置完全对应，比较类别和连续值 |
| K03 | 分类坐标＋特征矩阵＋独立条件组成 | 共同类别ID＋坐标／特征＋明确条件比例与分母 | 互补层次；当前组成来自独立条件表 |
| K04 | 同观测点／IQR＋雨云 | 同一对象×组别×数值 | 原始值、中心和分布共同展示 |
| K05 | 雨云＋已有估计区间 | 对象原始值＋同组别已有估计和区间定义 | 分布和估计互补；演示固定区间不称研究CI |
| K06 | 分组条件水平＋有序曲线 | 共同组别的条件值／区间＋已有X/Y曲线 | 条件水平与变化互补；不宣称对象配对 |
| K07 | 分类坐标＋同位置特征＋特征汇总 | 同对象坐标、类别、特征；冻结汇总 | 同一对象的分类、连续值与概括三层 |
| K08 | 分类坐标＋特征矩阵＋记录数量 | 同对象类别坐标＋同类别特征与数量 | 位置、模式和支持量共同展示 |
| K09 | 同对象坐标＋特征均值／比例点阵 | 对象ID、固定XY、类别、对象×特征值；检测阈值与分母 | 分类位置与同一批对象的特征强度、覆盖比例同时展示 |
| K10 | 同一矩阵：热图＋趋势轮廓 | 同一行×列矩阵、行身份、列顺序 | 色块比较整体模式，曲线比较行的相对轮廓与转折 |
| K11 | 同对象位置＋数量＋组成 | 同一对象ID与类别／坐标；明确计数单位与总体分母 | 同时看位置、支持量、类别构成；位置重叠不会隐藏数量 |
| K12 | 配对值＋同主体差值雨云＋已有估计 | 完整subject×condition值、同主体delta、已有estimate／bounds定义 | 展示个体变化、差值分布与估计范围三个层次 |
| K13 | 同XY：气泡量值＋六边形支持量 | 同一对象X、Y、独立size变量、对象单位 | 气泡看附加量值，六边形看重叠区域到底有多少记录 |
| K14 | 多实体网络＋同一邻接矩阵 | 同一节点清单、带符号权重的边、已知无边／未知规则 | 网络看拓扑，矩阵精确定位边；两者可以互相核对 |
| K15 | 同成员关系：二部网络＋矩阵＋UpSet | 同一完整对象×集合成员表 | 同时看共享对象、成员逐项关系与集合交集量 |
| K16 | 集合重叠网络＋同集合条件分数 | 共同集合ID的重叠权重、条件×集合已有分数 | 同时看集合之间关系和各条件的响应模式 |
| K17 | 同路径流带＋阶段边缘组成 | 同一已记录路径ID、各阶段类别与固定路径量 | 流带看对应路径，堆叠看各阶段总体构成；分母一致 |
| K18 | 同关系：带宽弦图＋数量矩阵 | 同一source×target非负weight完整表 | 宏观看分配，矩阵读局部数值；同一数量两种视角 |
| K19 | 已有富集三层图＋命中窗口 | 相同排名索引的已有曲线／命中／排序量、明确窗口 | 全景看已有信号，局部窗口看命中结构；窗口范围明示 |
| K20 | 多状态矩阵＋同对象事件数量 | 完整对象×特征状态、None／未知、计数去重规则 | 矩阵看共现，数量看支持量；按对象去重避免事件累加 |

## 进一步可组合的路由

下列是基于已有组件能力的组合方案；“可组合”不等于全部已有独立新增预览。以输入存在和对应关系成立为前提，先画单panel再组合，不能填造缺失统计量。

| 数据条件 | 可选组合 | 用途／须核对的关系 | 当前依据 |
|---|---|---|---|
| 同一效应表与已保存分类结果 | 火山＋堆积边缘＋效应数值表 | 同一过滤条件、对比方向和统计门槛 | P08/P10、P20；前两者已有完整组合 |
| 同一集合成员与已有集合结果 | 富集点／棒棒糖＋成员网络＋UpSet | 集合ID、背景、统计结果和成员关系来自相同版本 | P11、N03/N06；K15已有成员三联 |
| 同一成员表和对象量值 | 二部网络＋成员矩阵＋对象差异值／区间 | 同一对象键；成员矩阵和效应矩阵保持不同色限含义 | N03、P14/P20；K15已有三联 |
| 同一特征×条件分数与集合间关系 | 重叠网络＋分数矩阵＋已有排序树 | 集合ID与树叶明确对应；不把相似边当反应边 | N02、T34、K16 |
| 同一XY对象与差值诊断 | 散点＋边缘分布＋差值散点／箱／雨云 | 定义差值、单位；方法一致性不能只看相关 | R12/R13、P05/P22 |
| 同一完整配对对象 | 配对连线＋delta分布＋delta森林 | 独立单位、配对排除和delta方向一致 | K12已导出 |
| 多条件已有点估计／区间 | 分面森林＋效应矩阵＋支持量 | 同一效应尺度；各区间定义和样本量单独保存 | P20/P21/P14/P31 |
| 同一对象的类别和数值 | 分类坐标＋密度／六边形＋组成／数量 | 坐标点数不是独立样本数；分母对应输入对象 | K11/K13、N10 |
| 同一对象集合的多个特征 | 同位置特征分面＋特征相关矩阵＋均值／比例点阵 | 相同对象ID；相关结果由上游提供 | P07/R05/P13、K09 |
| 同一矩阵的固定行列 | 热图＋行轮廓＋列概括／数量 | 数据不重新标准化；排序和色限固定 | K10、P16/T34 |
| 同一变量对的已有关联及集合关系 | 相关矩阵＋关系网络＋区间/证据表 | 系数、p/q、方法和关联对象不同编码 | R05/R07/P18；K14网络矩阵 |
| 同一计数／已保存分箱结果 | ROC＋PR＋校准＋支持量 | 同一验证集合；基准率、区间和重采样定义明确 | P25/P26/P27；不重新训练 |
| 同一分类混淆计数 | 混淆矩阵＋各类已有性能＋样本量 | 不能从不同人群结果拼成一次验证 | P36、P31；正式统计结果待上游 |
| 同一训练运行 | 损失／验证曲线＋运行矩阵＋诊断轨道 | 共享epoch、运行ID；已有选择点不由外观挑选 | R14已组合 |
| 同一数量关系与阶段路径 | 流带＋组成＋数量矩阵／弦 | 真正对象路径才称迁移；矩阵边汇总不能识别全路径 | K17/K18 |
| 同一完整成员表 | UpSet＋成员矩阵＋对象量值分布 | 互斥交集定义一致；全0和未知分开 | K15、N06/P05 |
| 同一完整状态表 | 多状态矩阵＋去重数量＋条件构成 | 事件可重叠；人数去重；不把未知算无事件 | K20已有导出 |
| 同一排名索引 | 富集曲线＋hit轨道＋排序量＋明确局部窗口 | 保存全列表与窗口规则；不猜NES/p值 | K19已有导出 |
| 同一空间坐标/规则网格 | 连续场＋等值线＋横/纵剖面 | 同一量纲、色限和位置；上游提供网格/剖面 | N11、R23、P29 |
| 同一既有排名／量值表 | Bump＋量值线／森林 | 排名与实际量级分别解释，不互相替代 | N09、P20/P29 |
| 同一参考位置范围 | 信号轨道＋区间注释＋矩阵 | 参考版本、坐标体系、方向与边界一致 | P28/R22 |
| 实际结构与准确残基映射 | 整体丝带/表面＋局部＋置信度/距离/PAE矩阵 | 真实结构相机固定，author/label映射核验 | S01–S03已有真实导出；专用矩阵需实际输入 |
| 同一已审核结构比较 | 叠合全景＋位移值矩阵/轨道＋局部细节 | 真实对齐回执和对应残基；无回执不报告RMSD | 原生工具条件路由，未冒充本轮执行 |
| 同一有来源的机制/过程记录 | 流程＋结构窗＋已有表面/估计/计数 | 示意层、实际结构层与结果层各有来源 | R24布局原型；真实结构需提供坐标 |

## 组合验收

必须明确各panel是同一对象、同一类别、同一参考位置，还是同一主题的互补条件。共同颜色只对应相同身份；不同量纲分别保留图例与色限。统计点、记录数量与独立样本数分别标注。不要让上一个panel的色标解释另一个不同指标。

组合模板只负责排版，不自动联结缺失键、不合并图例、不重算统计量。compose_panels核对源文件哈希、共享主题和单panel范围；实际导出再看标签、比例和遮挡。相同数据的多视角组合适合解释和审阅，正式论文可按信息增量减到最必要的panel。
