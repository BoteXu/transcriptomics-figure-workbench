# 逐类检索与期刊图形设计审阅

本轮覆盖合并后的 **90 个基础图型**；不是新增 90 个算法。检索优先 2025–2026 年，按在线发表时间判断，不把 DOI 年份或卷期年份直接当作发表时间。所有图型都有现有入口、扩展方式与示例；检索结果不改变已实现能力的状态。

## 三种记录不能混用

- `journal-search-v092.json`：90 个图型的实际检索记录。部分查询成批返回，候选仅归属于查询批次，不能声称已确认对应单个图型、年份或图号。搜索命中不代表推荐。
- `journal-design-v092.json`：实际读过图注并看过原图的 **7 篇论文、8 张组合图**，逐项记录借鉴、舍弃和实施范围。未复制第三方图片、代码、数据、模型或字体。
- `assets/editorial-gallery`：本轮实际渲染与逐张屏幕自检的 27 个示例；其中 23 个沿用原始冻结输入，4 个为明确虚构的 marker 数量布局压力样例。它们的验收记录不覆盖所有搜索候选。

搜索结果中的日期、图注摘要或预印本身份要到原站核对。领域无关、无明确图号、商业图形聚合页、检索错误及不能核查的候选不作为设计依据。没有找到更优近期范例时，保留已验证画法及原始方法依据，不能用普通搜索结果替换默认方案。

## 默认选择顺序

1. 明确科学问题、独立单位、必要通道和最终用途。
2. 从同一基础图型的已实现扩展中选择信息充分且易比较的画法。只有输入真实具备对应通道才启用扩展。
3. 对比现有示例与已核查来源，给出选择理由；复杂程度、期刊名和颜色数量均不作为质量分数。
4. 主图优先清楚的阅读顺序与定量比较。长标签、多 marker、多通路的完整结果转到阅读版或补充图，保持范围完整，不静默删行。
5. 根据数据量和用户指定行列数调整画布、标签区与图例区。最终导出后重新看图；几何检查不替代视觉判断。

## 按图型采用与舍弃

以下各项同样适用于现有入口的别名。完整逐项对应表见 `journal-form-review-v092.md`。

| 图型族 | 更值得优先采用 | 明确避免 |
|---|---|---|
| PCA、嵌入、特征图 | 可用时组合给定椭圆、边际分布、群体数量；特征图共享原始坐标、背景细胞及声明的表达色标 | 为好看重新拟合嵌入、猜置信椭圆；不同色标却暗示可直接比较 |
| 注释证据 | 一张总览与按身份分块的 marker 矩阵；每亚群独立的定位、跨群特异性、连续 marker 面板 | 把组成、多个亚群及全部 marker 塞进一个拥挤主图；把细胞数当供者数 |
| 箱线、小提琴、雨云、配对、ECDF | 原始独立观测、有效样本数、效应及给定区间；配对线有真实 ID | 小样本用平滑形状掩盖观测；随机抖动改变量值；添加未经计算的显著性 |
| 火山、MA、排序效应 | 保留方向、效应、FDR 与精确计数；兼容时加边际或堆叠分布并限制标签 | 黑色候选覆盖科学颜色；混用原始 P 与 FDR；只靠颜色声称效应大小 |
| ORA、GSEA、通路支持 | 有效背景、集合版本、NES/FDR、完整命中及排名度量；通路行与成员证据对齐 | 将 ORA 画成带方向 NES；假造 leading edge；圆形布局遮盖长标签或完整范围 |
| 热图、点阵、相关矩阵 | 一次清楚的标签区，明确组块与尺度；均值、检测率和成员关系使用不同通道 | 为扩充图库重复近似热图；将零值、非成员、缺失和未检验混为一色 |
| WGCNA、树、网络、弦图 | 模块身份一致，诊断到模块-性状到成员证据；网络显示真实边类型与权重 | 装饰性毛线团、无依据的方向箭头、用节点大小暗示未经证明的中心性 |
| 轨迹、曲线、向量场 | 给定顺序、分支、方向与区间，分面展示状态；总览连接局部定量 | 为美化推断 pseudotime、速度或平滑趋势；线的相交被误解成真实转换 |
| 组成、集合、流向 | 相同分母与顺序；类别少可环图，精确比较优先堆叠或对齐柱；多集合优先 UpSet | 3D 饼图、无法辨别的细弦；不同分母直接连流；集合交集当因果路径 |
| ROC、PR、校准、决策、生存 | 明确终点、时间窗、外部队列、基线、区间和风险人数 | 把截断坐标产生的视觉优势当效果；把 0.5 当通用 PR 基线；无依据风险表 |
| 地图、切片、配准、空间图 | 坐标系、方向、尺度和真实配准证据；区域总览与局部放大对应 | 用图片叠合的观感证明配准成功；将缺失区域填成零 |
| 基因组、剪接、接触、变异后验 | 物理坐标对齐、明确组装/链/单位、给定 credible set 与 splice counts | 按类别等间距冒充基因组位置；把 PIP、P 值和 LD 互换 |
| 分子结构、位点置信度、序列 logo、谱图 | 结构来源与链映射、原始置信定义、明确残基或质量轴；配对谱保留方向及单位 | 重新构造缺失结构、将 pLDDT 当实验准确性、把镜像强度当负丰度 |
| 森林、平衡、残差、QQ、Bland–Altman、漏斗、规格曲线 | 估计对象和零/一基线明确；区间、检验家族、规格选择及诊断范围可追溯 | 仅显著结果、未经分析的区间、用视觉对称性证明无偏倚 |
| 雷达、径向、地平线、马赛克、方格、3D 曲面 | 用户明确偏好且量纲与面积含义适合时使用；配有直角坐标或数值阅读版 | 因为稀有或“高级”就优先；用面积、压缩色带或透视隐藏精确数值 |

## 本轮落实的变更

- 富集页改为统一通路行与单一标签区；成员证据采用完整的成员格，明确非成员与零效应成员；FDR、NES 和 gene effect 各有独立含义与图例。
- 注释页明确 marker 的归属分块。每亚群默认先定位与特异性、再连续展示 marker；支持 2、4、8、12 个 marker 及显式自定义网格。
- 动态增加长 marker 标签、纵向色标及下一行标题所需的空间。标题字号遵从主题；导出标记区扩展之后仍检查实际几何位置。
- 23 个原有示例输出已更新；旧版本快照和修订前 PNG 保留。4 个额外样例只检查显示容量，不代表发现了额外 marker。

这些图的屏幕自检、软件回归、纸张校样与科学有效性分别记录。新数据、新文字或新布局均需要重新自检。
