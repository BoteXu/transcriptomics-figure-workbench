# v0.7 review scope

## Actual changes

Fifteen actual examples use ten clarity modes. Eleven exports redesign or split six original sources: T35, R16, R11, E34, E41 and E42. Four additional task views show observations with an upstream effect distribution, decision curves, a dedicated precision–recall presentation and rank spans. Generic PR drawing existed previously; this is a refined dedicated route, not a first implementation of PR analysis.

Title weight and scale were reduced, long engineering notes moved to each figure's metadata, and short semantic captions retained. Contribution mid-tones were strengthened after visual inspection. Physical image panels were reflowed and coordinate/colourbar separation repaired. Complete original points, matrices, shares, pixels and source orders are retained; no scientific analysis was executed.

## What was checked

- All fifteen PNGs decoded; all fifteen exported PDF pages parsed for page/text bounds and scaled body font size. Exported PDF body lower-decile size is at least 7.95 pt at 178 mm. The pre-export 7.5 pt blocking gate also passed. These are measurements, not beauty scores.
- All fifteen complete PDF pages were individually inspected on screen from Poppler renders at nominal 178 mm / 96 dpi. Review records bind PDF, PNG and inspected-screen-image hashes, six visual checks and specific notes. This is a self-review; there was no independent reviewer or calibrated paper proof.
- Runtime checks preserve all 1,080 profile vertices, 4,550 stored effects plus 52 summaries, 6,650 class contributions plus 45 supplied shares, all 47 membership links and physical pixel arrays. Thirty malformed cases were refused across fifteen examples; file inputs remain unchanged.
- Discovery has 124 Python callables and 82 fixed aliases. Design planning has nineteen input structures; these counts are not scientific methods. Optional dependencies are loaded only for the chosen route.
- Existing 108 historically audited renderer modules are byte-preserved. Historical examples and v0.6 reading PDFs keep their original bytes and inspection scope.

## What remains open

The combined browser contains 458 exports. The original 140 size warnings are deliberately retained on their original wide exports; five flagged original sources now have linked alternatives, and T35 has an additional aesthetic replacement. This does not mean all 140 originals were reflowed. [The explicit remaining ledger](../../../examples/review-v070/remaining-size-review.json) includes each original hash, warning and alternative status. Dense R04/R24 dashboards and P10's original marginal layout remain priorities for a later whole-panel redesign.

New examples are limited to the supplied labels, lengths and data shape. Different names, dense overlaps, large grids and colour requirements need a fresh render and actual review. The class-specific contribution layout uses display jitter, not a recomputed density or SHAP beeswarm. Pixel panels illustrate procedural grids and are not anatomical or diagnostic validation. Literal evaluation fixtures do not establish any model's performance or clinical utility.

Scientific validity, general backend acceptance and manuscript acceptance are not established by these software and visual checks. See [exact contracts and attribution](clarity-views-v070.md).
