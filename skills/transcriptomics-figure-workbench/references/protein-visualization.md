# 蛋白结构可视化：按输入数据与表达选择

蛋白结构图属于本 skill 的计算生物学绘图入口。真实三维结构交给已安装 Molecular Structure Viewer 或用户已有 PyMOL/ChimeraX 环境；Matplotlib 负责统计面板、标签与组图。不为增加绘图目录重复安装预测或对接后端。

## 展示方式与输入

| 表达 | 需要的数据 | 能看见什么 | 建议外观 |
|---|---|---|---|
| 丝带 / cartoon | PDB 或 mmCIF 的原子坐标、模型和链选择 | 整体折叠、螺旋、折叠片和连接环 | 浅灰背景或白底；一到两种主色；保留柔和立体阴影 |
| 链 / 区域分色 | 结构＋准确链 ID 或残基范围 | 各组成部分的位置与界面 | 伙伴蓝色与紫色；关注区域洋红；不靠过量颜色编码所有残基 |
| 分子表面 | 结构＋表面定义与探针参数 | 外轮廓、接触区域和口袋形状 | 半透明表面叠加丝带，或一个伙伴表面、另一个伙伴丝带 |
| 棒状 / 球棒局部图 | 结构＋明确残基/配体 ID | 原子布局、侧链与配体朝向 | 背景蛋白淡化；局部使用元素颜色；标注克制 |
| 连续数值映射 | 结构＋可靠映射的逐残基/逐原子数值 | 置信度、实验 B-factor 或其他已有数值的空间分布 | 顺序色图；有符号变化才用中心分歧色图；写明色标范围 |
| 两结构叠合 | 两份结构＋对应链/残基或已有对齐结果 | 构象异同及对应区域偏移 | 两种主色，固定同一相机；有实际对齐回执才报告 RMSD 与对应数量 |
| PAE / 接触 / 距离矩阵 | 已有矩阵＋准确的残基索引映射 | 配对关系和区域不确定性 | 二维热图与结构窗并排；索引不能自动当 author 残基编号 |
| 多帧与动态展示 | 拓扑＋轨迹或多模型坐标＋帧选择 | 已有构象随时间/帧的变化 | 固定相机、共同颜色；记录步长、PBC 和参考对齐；大轨迹计算留在服务器 |

## 复现 R24 的结构部分

1. 确认原始文件、实验/预测来源、模型、链、assembly 与缺失片段。仅有参考截图时保留“示意轮廓”的标记，不能还原原子结构。
2. 为整个复合物保留统一坐标框架。选择一个伙伴为低饱和蓝色表面，另一个伙伴为紫色丝带；只将用户指定的局部区域高亮。区域定义来自链和残基表，不从颜色猜测。
3. 调整相机，使界面可见而整体轮廓完整。全局图和局部放大图分别注明选择范围；多候选使用一致视角策略和缩放。
4. 数值标签来自已有结果表。例如亲和常数必须含单位、方法和来源，不能从结构形状、接触距离或预测置信度推算。
5. 导出足够分辨率的 PNG 与完整 scene/render sidecar；在矢量流程图里排版这些结构窗。结构像素仍是栅格，SVG/PDF 容器不让分子原子变成可编辑矢量。

## 当前可用工具的操作流程

先读已安装 structure-viewer 的 SKILL.md。用户未给结构而请求普通演示时用内置 GFP 示例；用户给了 PDB/mmCIF 则只打开该文件。一个请求只开一个 viewer，后续对比结构加到同一窗口。实际 mounted、rendered 回执确认后再称加载完成。

读取 `get_context` 和 `get_state`，核对 object、链、模型与 author 编号。通过 typed scene layers 加 cartoon、surface、sticks 等层；用 `expectedRevision` 防止覆盖用户在窗口里的新调整。复用既有 scene endpoint，避免猜测原子选择或虚构对应关系。层的选择与相机是审美参数，原始坐标保持不变。

用 `validate_render` 检查目标和工作量，再 `render_image`。输出路径由 viewer 的 publication capability 决定，不能猜测它等同当前目录，也不能覆盖未知结果。成功必须有图片和 `.render.json`，再检查实际图片边缘、遮挡、文字、透明度与来源哈希。必要时固定相机位置和 target/up；存在显式 position 时不要依赖仅改变 zoom 来完成留白。

本轮已真实加载内置 GFP，并导出 cartoon、surface、透明 cartoon＋A 链 author 65–67 局部球棒三个例图。使用 Mol* 5.11.0，最终实际图片已检查完整轮廓与留白；这是公共示例结构的可视化验证，没有对用户参考中的结构、亲和力或优化算法进行分析。

## 残基与科学解释

- 保存 object、model、assembly instance、author/label chain、author/label residue 和 insertion code，避免同号残基误指。
- 预测结构的 pLDDT 与实验结构的 B-factor 含义不同；未确认来源时不能把 B-factor 列自动标成置信度或柔性。
- 接触、距离和表面几何不自动说明键、能量、活性、亲和力或因果关系。表面电势还需要可靠电荷/势网格及单位，不能用几何表面随意涂色冒充电势。
- 对齐必须使用真实对应与回执；两个结构放在同一窗口并不等于已经叠合。
- 用已有 PyMOL 时遵循其 skill、环境和许可要求，保存 `.pse`；本轮未安装或运行 PyMOL，不声称该后端已验证。

结构样式与数据表绘图是两个入口。图库 R24 的几何示意模板可用于流程排版；真正结构窗应替换为来源明确的三维渲染图。
