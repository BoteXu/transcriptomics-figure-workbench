# 十五套科研配色色卡与语义映射

只有明确写有“科研配色方案”的七张用户海报命名为 C01–C07 色卡。普通图里的配色是图型外观参考，不追加为色卡。

原七张色卡共 52 个颜色条目，包含不同卡之间重复的颜色；这不表示 52 种互不重复的颜色。所有色卡默认注册为 categorical，不按列表顺序自动解释为科学连续变量。

## 连续变量使用单独语义映射

以下五个 `_signed` 调色板是本次独立设计的中心分歧扩展，不是声称从未读的微信正文中提取的原教程：

| 注册名 | 负值 → 中心 → 正值 |
|---|---|
| card_01_signed | #3F3770 → #FFFFFF → #D6456C |
| card_02_signed | #B2CDD8 → #FFFFFF → #E5A08A |
| card_03_signed | #036EAD → #FFFFFF → #DD656D |
| card_05_signed | #90A4C4 → #FCEDE9 → #F29F95 |
| card_06_signed | #506AAA → #FFFFFF → #E17692 |

数值映射规则：类别使用固定颜色字典；非负幅度用顺序色图；相关/效应等有符号值用明确中心的分歧色图。原海报含的连续示例若有另一套颜色，登记为独立应用映射，不把整张类别色卡直接当作渐变。组别改变不循环复用颜色，超出容量则分面或明确提供项目色。

## 普通图的外观颜色

R01–R24 的近似视觉颜色、粘贴文本的三个准确 Hex，以及连续地图/矩阵扩展，另在 reference-palettes.json 记录 provenance。这些不是第八张或更多色卡。截图估计色不声称是作者原始色值。

## 审美调整准则

- 同一变量或组在所有图保持相同含义和颜色。主图留一到两种强调色，其余层降低透明度或饱和度。
- 白底浅色可作填充与范围带，文字和细轴仍用深色；减少单凭相近色识别类别的情况。
- 同时使用符号、线型或直接标签帮助辨认。颜色字典和连续色限单独冻结。
- 当前七卡未经过色觉缺陷或灰度可读性正式验证；参考效果不等于所有输出场景适用。投稿前按最终尺寸检查。

## 调用入口

新课题默认按project-style.md生成统一project_theme.json。分组字典固定身份，连续角色独立指定；C14/C15不能作为类别基底。category_map和reference_cmap仍供明确低层调用。

plot_palette_panel绘制单独panel；plot_palette_plate保留旧整页应用复现兼容入口，不作为新图默认输出。色卡、独立panel、组合图各有入口。
