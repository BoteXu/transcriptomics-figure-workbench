# 网络、通路关系与多层数据扩展

按需要的数据和表达选择，不按物种或领域归类。以下12个N例子已有实际合成预览；其中多实体、重叠、二部和层次网络共用一个参数化网络画法，并不重复登记为四个算法。九个新增Python绘图函数没有引入新的科学分析引擎。

| 例子 | 画法 | 输入数据 | 表达 | 边界 |
|---|---|---|---|---|
| N01 | 多实体有符号网络 | 节点ID、类型、类别、固定XY、面积；边的端点、符号、权重及关系来源 | 形状区分实体类型，颜色固定类别，线色表达正负，线宽表达给定权重；找跨类型关联和中心连接 | 关联不画因果箭头；面积若只是排版强调必须注明；位置来自显式输入 |
| N02 | 集合／通路重叠网络 | 集合节点表＋已提供的集合间相似／重叠权重及定义 | 看哪些集合成模块、共享关系是否密集 | 重叠／相似不代表通路间反应；不自动计算相似度或筛选弱边 |
| N03 | 实体—集合二部网络 | 实体与集合节点表＋明确成员关系；类别／量值另列 | 看一个实体属于哪些集合、哪些实体被多个集合共享 | 成员关系不等同调控；未知成员不能当0；高密度优先并排矩阵 |
| N04 | 带宽编码的加权弦图 | source、target、非负weight、明确扇区次序与类别字典 | 带宽看关系量、扇区长度看输入量合计，比较数量在类别间怎样分配 | 与细线圆形相关网络区分；当前无方向；不能把负值直接当宽度 |
| N05 | 跨阶段流带／Alluvial | 路径ID、各阶段的类别、同一路径weight和阶段次序 | 带的高度表达数量，追踪输入已经记录的跨阶段类别路径 | 边缘比例无法恢复个体迁移；不是从横断面推断轨迹；路径数量每阶段守恒 |
| N06 | 集合交集 UpSet | 对象ID×集合的完整0/1成员表、对象单位 | 顶柱为互斥交集数量，点阵为参与集合，侧柱为各集合总量 | 完整成员表才能表示0；全0对象保留；互斥交集与包容性交集定义需明确 |
| N07 | 多状态事件矩阵／OncoPrint形式 | 行×对象的完整表、可并存的状态清单、明确None与未知 | 一个格内分层色块看状态共现、哪些对象具有多个事件 | 状态不是连续量；None须确认为测量后无事件；多事件不能重复计为多人 |
| N08 | 已有富集曲线＋命中位置＋排序量 | 相同排名索引的运行分数、命中位置、排序量、集合ID | 同时看已有曲线起伏、命中集中在哪段，以及对应排名量值 | 只画已算结果；不计算富集、NES或显著性；排名位置不是基因编号 |
| N09 | 排名变化 Bump | 类别／实体ID×阶段的已提供rank，阶段顺序 | 看同一实体在阶段间排名怎样上升、下降、交叉 | 不重新排名；保留并列；反向纵轴明确1最高；排名不能表达原量值差 |
| N10 | 密集XY的六边形计数 | 对象ID、X、Y、对象单位、给定分箱粒度 | 减少密集点重叠，同时用颜色看每个空间格内的记录量 | 描述性显示分箱，非独立性证据；计数不是其他变量均值或概率密度 |
| N11 | 二维连续场＋等值线 | 完整X×Y数值网格、量值单位、色限、中心与等值层 | 同时看连续量的空间分布、梯度方向与相同量值区域 | 不拟合响应面；已知网格缺口不填0；只有比较同量纲场才共用色限 |
| N12 | 给定层次的节点关系图 | 明确parent→child关系、节点类型／值／位置 | 看已有层级与父子关系，节点形状／颜色可增加类型信息 | 不是新聚类、祖先重建或调控推断；箭头只表达声明的父子关系 |

## 多实体网络：新增参考R25

把节点和边分开准备，再以record_type合入一张长表，完整表随图保存。node需要node_id、label、entity_type、group、x、y、area；edge需要source、target、weight、sign。sign为-1/0/1，weight为给定正数。shape_map将gene映射三角形、metabolite映射方形、community映射圆形；名称可换为任意实体类型，但形状字典必须明确。颜色来自课题身份字典，线色来自正／负／未给符号角色。area可以是测量量，也可以是明确标注的排版强调，不能猜成中心性或丰度。

relation_semantics明确关系是关联、成员、重叠、已知反应或父子关系。当前R25/N01为无向关联：没有因果箭头。输入没有边的统计来源时不能写“发现新通路”。不同条件比较网络时保留共同节点布局、面积比例、权重比例和类别色；缺失节点／不可估计边另表记录，不能自动当无边。

多实体密集图保留全部节点和关系；可以显式选择子网、标签子集、节点/边透明度与分面。选择规则须保存。把未标出的标签另列表，而不是把节点或弱边悄悄删掉。优先用网络＋矩阵并排、模块分面和外侧图例；密集交叉线的透明度是外观，不能改变权重。

## 画法来源与执行范围

以下均来自作者或官方文档。本skill代码为原创轻量静态适配，借鉴视觉表达和输入格式；没有声称运行这些R软件或Cytoscape，也不复制其分析代码或图像。

- [网络映射与多实体形状](https://manual.cytoscape.org/en/stable/Styles.html)：Cytoscape作者手册：表属性映射到节点／边样式。未运行Cytoscape原生软件。
- [成员／通路网络与成员热图](https://yulab-smu.top/biomedical-knowledge-mining-book/enrichplot-networks.html)：enrichplot作者文档：成员网络、重叠网络、关系热图和交集视图。没有调用其分析引擎。
- [已有富集曲线与分布](https://yulab-smu.top/biomedical-knowledge-mining-book/enrichplot-gsea.html)：作者文档：运行分数、命中位置与排序量共享排名轴。
- [加权弦图](https://jokergoo.github.io/circlize_book/book/the-chorddiagram-function.html)：circlize作者书：邻接矩阵／边清单、数量宽度、扇区和方向定义。当前实现为原创静态适配。
- [路径流带](https://corybrunson.github.io/ggalluvial/articles/ggalluvial.html)：ggalluvial作者教程：分类重复记录的宽／长路径格式及对应数量。
- [集合交集](https://jokergoo.github.io/ComplexHeatmap-reference/book/upset-plot.html)：ComplexHeatmap作者书：对象成员矩阵、互斥／包容性交集与支持量。
- [多状态矩阵](https://jokergoo.github.io/ComplexHeatmap-reference/book/oncoprint.html)：作者书：同一格中并存事件的不同图形编码；不把缺测视为无事件。
- [六边形计数](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.hexbin.html)：Matplotlib官方API：分箱中对象数；额外变量聚合需另行定义。
- [连续网格等值线](https://matplotlib.org/stable/gallery/images_contours_and_fields/contourf_demo.html)：Matplotlib官方示例：输入网格与给定等值层，未拟合连续场。

## 组合入口

成员关系使用K15，集合关系与条件分数使用K16，定量弦与矩阵使用K18，流带与组成使用K17。完整匹配规则见[combinations-router.md](combinations-router.md)。

未知、未检测、缺失与已知0必须分开。跨平台ID先由上游完成映射，绘图不补全通路，不推断成员关系或干预效应。
