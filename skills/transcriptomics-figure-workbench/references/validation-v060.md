# v0.6 检查范围与剩余限制

## 实际图像检查

本轮查看了438张既有导出的完整图像或组合概览；独立图使用每页两张独立全图的有界屏幕视图，组合使用相同方式查看全布局与面板身份。修订后的32张及新增5张另行检查，并将说明绑定实际 PNG 哈希。

当前443个导出分为317张独立图和126张组合。317张记录为单图屏幕检查，126张为组合概览与面板身份检查；图像查看器可能缩放。它们不代表443张均达到178 mm论文版心、全部细小文字已在原像素检查、或全部PDF页已逐页人工核对。

## 具体修订

- 28张明确使用离散身份色的 T/N/M 图采用固定色相映射；原始色卡和连续色阶不因此改变。
- P10主体散点原为嵌入图像。重新使用原绘图对象和精确源表，同步修改主体点色，再统一边际图及图例，避免只有图例变色。
- R05通过原绘图器的语义色阶接口同时更新椭圆和嵌入色条；数值、椭圆公式和[−1,1]范围保留。
- R08三组使用更清晰的青/珊瑚/紫色；R21正负方向采用蓝/珊瑚；M01的Neither中性化，X-only/Y-only/Both分别蓝/珊瑚/青。
- T35保留全部供应坐标和标记，仍显得密集。正式稿件宜使用明确配置的细标记曲线或独立小面板；本轮没有删点来制造清爽效果。

## 新示例

REF01–REF05均有实际 PNG/PDF/SVG、准确TSV和FigureSpec。渐变 GSEA 的两层线段逐顶点核对供应的 ES；曲线区间和评分差值分别验证；输入越界、未知选项和错误通道会拒绝。原生 GseaVis、ggprism、linkET、corrmorant 和 R 分析包未执行。

REF01使用细灰底线解决渐变中性色附近曲线不清楚的问题；REF05将关联与Mantel统计分开，不以星号或色阶编码原始p值。原始p值保留于准确表格，该展示范围已注明。

5张新增示例另行查看了名义 CSS 178 mm 的独立屏幕截图；这不包含显示器物理标定或纸张打样，记录见精修图库的 `nominal-screen-review.json`。

## 阅读版

阅读PDF覆盖全部443个当前导出：完整概览、统一缩放的重叠区域及组合的独立图导航分别记录。每张源PDF及每卷结果都绑定哈希，压缩前后解码绘制指令一致。原始组合保留旧组件版本，新配色组件单独显示，不能把新组件的验收追溯套用到旧组合。

正文最小字号检测、区域覆盖与导航结构属于自动检查。实际选页导出检查与完整443张PNG检查分别记录；不声称所有阅读PDF页均经人工查看。阅读PDF不是最终论文拼版，栅格/轮廓字体仍需实际放大核对。

实际交付为6卷、681页；全部页解码和页面结构检查完成，12页经Poppler实际渲染并查看，涵盖密集图首末分块、分类图、径向图、组合导航及新增示例。边界截断是带重叠和位置地图的阅读分块，不是独立论文面板。

## 验收层次

文件哈希、PNG解码、PDF可读结构、输入/renderer契约、同源通道、浏览器交互和逐图自检分别记录。保留v0.5的139个旧主图尺寸预警，不因提供阅读版就自动清除。实际修订的主图重新进行字号筛查，当前数量以 `examples/review-v060/review-index.json` 为准。

当前主图在178 mm宽度下有140个字号预警。阅读版解决放大核对，正式稿件仍需按版心重排或选择明确的面板范围；本轮不把这些主图标成最终尺寸通过。

108个历史审核过的绘图模块、260个稳定编号、原图/源表、既有R对应函数、第三方署名以及私有配置保护继续保留。任何检查均不建立生物学独立性、因果关系或科学结论。
