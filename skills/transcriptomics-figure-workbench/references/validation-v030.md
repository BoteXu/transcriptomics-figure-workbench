# v0.3 acceptance scope

This version retains the established drawing library and rebuilds discovery, configuration, lazy loading, export orchestration, offline interaction and review. Historical v0.2.5 assets remain preserved.

## Checks

- Source-derived inventory currently accounts for 120 Python functions and 78 fixed aliases. The original 58 alias bindings are retained. Discovery and preflight import no NumPy, pandas or Matplotlib.
- Strict preflight checks selected local TSV structure/bounds, explicit provenance, registered parameters, category capacity, configuration and source bindings. It is not complete scientific or every-renderer semantic QC.
- Eight frozen synthetic renders cover MA, ranks, paired observations, stored ROC coordinates, supplied effect intervals, signed matrices and two typography replacements. SVG/PDF/PNG and exact table receipts are generated; the matrix checks 600-DPI PNG/TIFF. Restyles preserve the quantitative geometry fingerprint.
- Existing bundles are preserved. Changed data/source invalidates saved plans. Changed exports invalidate prior visual decisions. Injected visual-check values in software tests are labeled and do not count as actual visual inspection.
- Browser acceptance exercises actual catalog search, historical source selection, safe SVG text previews, before/after views, configuration export and composition drafts. Browser findings and actual reviewed image hashes are recorded separately in repository validation artifacts.
- The first eight mechanical fixtures failed aesthetic review. The new [12-image mode gallery](../assets/aesthetic-gallery/index.html) has six rebuilt modes and six extra entries. Final-size text geometry checks and encoding checks cover count areas, exact units, band crossings, ordered coordinates, mirror scales and unchanged paired Y values. Actual inspected images and unresolved scope are listed separately in the aesthetic self-review.

## Boundaries

The inventory is not 116 new algorithms or 116 new scientific validations. The legacy drawing-family directory, historical compositions and native routes remain; supplemental encodings are listed separately. Source availability, software execution, visual inspection and scientific acceptance remain different states. The Python/R scientific backends are unchanged. No automatic installations or upstream analysis engines are added.

Studio does not render unknown data, infer original parameters, replace quantitative colors or certify scientific results. Its board is a composition draft; formal composition uses the existing checked bundle assembler. Font previews depend on browser/system fonts. Profiles and raster choices require a final redraw and final-size inspection.

Public examples are synthetic and source labels are portable. Private profiles, data, machine paths, project state, credentials and logs are excluded. Host computation and memory rules retain precedence.

## Complete atlas acceptance

The complete 400-export scope (274 singles and 126 compositions) now has individual actual PNG inspection records. Each record binds exact PNG/SVG/PDF hashes; source tables and component SVGs retain separate bindings. Automated browser text checks are advisory. Structural PDF checks do not imply PDF pixel review. See [full-atlas review](full-atlas-review.md) for corrections, scale limits and reproducibility.
