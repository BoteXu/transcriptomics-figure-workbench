# 分析结果模块与可组合表达

按结果的数据结构选择画法，同一领域也可能需要多个互补panel。下面列出的分析均为结果来源或候选路线；本skill绘制已有结果，不负责执行分析。

|结果模块|所需数据和表达|已保存模式与组合|
|---|---|---|
|剪接与异构体|样本×物理覆盖区间；junction起止、整数支持数和布局层；转录本外显子区间。覆盖和弧宽分别表示量，弧高只排版。|E43；可与已有事件效应森林、PSI矩阵组合，必须明确同事件/样本/参考坐标。|
|精细定位与共定位结果审查|共同变异ID和物理位置、分信号PIP、已给可信集。每个信号使用共同位置轴，成员形状与高度独立。|E44并入棒棒糖/评分模式；可与E28全局关联、E29局部轨道组合。不同信号的PIP不要求总和1；同位置峰不证明共定位。|
|预测校准与决策评价|固定分箱、平均预测概率、观察比例、给定区间、真实分箱n；同群体的策略×阈值净获益及参考约定。|E45、E46、K41；已有ROC/PR、混淆计数和模型诊断可补充。K41不是一个替代所有验证的指标。|
|调控活性与贡献分解|调控因子×样本有符号评分和覆盖定义；一个指定样本/因子的完整加性贡献、基线、总量。|E47、E51、K42；矩阵Regulator A/S01的0.62与瀑布总量0.62明确对应。不能把评分或贡献当因果作用。|
|通路共享与冗余|条目×条目已有相似矩阵、成员全集、定义和ID版本；也可提供条目-成员二元关系和效应。|E48作为矩阵模式；与E34成员流线、E01富集点阵、E08成员弦或UpSet组合。不得为好看而删除重复富集条目。|
|网络参数敏感性|明确参数网格、固定节点全集、已有相似/分区一致性指标及参考分区。|E49作为矩阵模式；可与已有树、网络、模块性状及成员评分组合。算法重复或空模型不是生物学重复。|
|WGCNA及已有模块结果|软阈值诊断、树和叶ID、模块标签、模块×性状结果、TOM/adjacency、MM/GS及明确网络边。|K38/K40与E35/E36/E37；[WGCNA路由](wgcna-visualization-router.md)保留独立panel和两个模式。|
|动力学与返回轨迹|运行ID×物理时间×已给指标/分块范围、单位、参考和独立运行定义。|E50并入有序曲线；可与E32多层范围、E12分布、已有残基/结构视图组合。帧或时间分块不能充当独立运行。|
|染色质与已有位点信息|物理分箱位置对接触量和同分箱轨道；位点×字符的非负已给高度、字母全集和定义。|E39、E38；热图/轨道与序列字母高度互补。频率、概率、bits不可混称。|
|蛋白/结构与功能注释|真实PDB/mmCIF模型、链/残基对应；已有序列置信度、相互作用和功能证据表。|S01–S03、已有残基曲线、E40枝长树与R25多实体网络；[结构路线](protein-visualization.md)区分真实坐标和示意流程。|
|影像与空间结果|已配准规则物理网格、背景强度、分类/连续叠加、明确方向；或两幅同尺度已配准数组。|E41、E42，均有内部横/纵模式。背景、标签、棋盘、差值各有含义，不执行分割或配准。|

新增E43–E51均保存TSV、style.json、PNG、PDF、SVG和元数据。E43/E44/E51使用scripts/figure_analysis_results.py；校准、曲线和矩阵复用已有通用函数。全部固定入口通过render_frozen_table.py读取字符串ID与明确数值通道。

组数、曲线数和外显子行数按输入扩展；颜色必须登记到课题主题，不能循环猜颜色。长名称、导出字体和最终图尺寸仍需实际检查。K41/K42中的两个panel均有独立导出，横向与纵向组合分别保存。

本轮检查Biomni当前目录以及advanced的调控评分、预测评价、通路共享、网络敏感性和MD摘要工具。network_render与regulatory_activity的select_tools调用只返回规划。另用新进程调用molecular_biology.guide_molecular_drylab(task="splicing")：实际结果为plan_only、submitted=false，提示事件/转录本目标、junction覆盖、参考和测试全集。缓存目录旧版本与当前源码/配置失效状态分别核对；没有将历史成功或import_ready当作上游分析验收。私人回执不放入公开包。
