# v0.2.5 验证范围

新增 `figure_qc_de.plot_frozen_qc_de` 和一个固定 `qc_de` 表格适配器，提供八个冻结摘要模式。此前 108 个函数和 260 个稳定示例保持；新增入口使 Python 绘图函数为 109，固定表格适配器为 58。八个模式不是八种新算法或新图形家族。

`tests/check_qc_de.py` 在独立 CI 环境检查：八种模式、输入不变、MA/排名的真实坐标、极坐标柱长、计数、P 值 bins、空总数不造假、重复/缺失身份、非有限/布尔值、错误顺序、遗漏分类、形状冲突与坐标截断拒绝。导出走既有精确 TSV/JSON/hash/原子目录发布契约。

合成预览初始为 `RENDERED_UNREVIEWED`。实际渲染、视觉审查、原脚本统计正确性和科学有效性是不同状态；须查看同版的 `examples/qc-de/validation.json` 和另列的视觉审核记录。本机内存准入未通过时不初始化绘图测试环境，改在独立 CI 生成这些合成预览。

原脚本的 OLS、PCA、填补、聚类和归一化未执行，未纳入新绘图入口。源文章正文与粘贴代码未做逐字比对；原代码/图片未再分发。原有 R 后端、真实组学后端及 TIFF 导出不在本次新增验证范围。
