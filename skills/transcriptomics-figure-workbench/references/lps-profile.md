# Optional private project profile

This public package has no default research project, private cohort, target hypothesis or exclusion list. The historical filename is retained for relative-link compatibility.

When a user explicitly selects a research project, keep its profile in that project's private directory. Record the study question, independent unit, assay, contrast, units, denominators, source versions, exclusions, missingness, uncertainty definitions and negative findings. Link the profile to frozen result tables and actual review receipts. Do not infer those facts from a figure style.

Select one project_theme.json for categorical identity, continuous scales and typography. Store project-specific profiles, paths and scientific results outside this distributable skill. Unknown sample relationships remain unknown; a library, cell or frame is not automatically an independent biological replicate.

This profile is a contract template, not an executed analysis or a project-specific scientific claim.
