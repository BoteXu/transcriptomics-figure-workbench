# v0.11.0 · 综合科研绘图工作台

本版将当前已验证的多组学、计算生物学与计算机建模绘图能力整理为新的完整安装包，保留 v0.10.0 及更早版本的资产与编号。

## 本版纳入

- 42 个原历史配方的当前 FigureSpec、准确冻结 TSV、默认／自定义布局和实际导出。
- 三维散点与完整正交投影、规则体素体渲染、分子轨迹关键帧／GIF／离线逐帧播放。
- 45 种方法的小／中／大数据和自定义布局：135 份不同冻结输入、180 张单图、45 张完整组装页。数据量或布局变化不算额外方法。
- 当前综合绘图库、58 章分析目录、bulk／单细胞的丰富默认画法及逐分析配套。雷达、三维曲面和旧画法继续保留。
- 重写的综合 README，包含全部 42 项的实际图片、输入、配置与调用步骤。安装包说明自动适配包内路径；仓库专有历史页面固定链接到本版源码。

## 下载与校验

- `transcriptomics-figure-workbench-v0.11.0.zip`：完整可安装 skill，包含当前离线目录、示例和可移植 README。
- `RELEASE_SOURCE.json`：精确源提交、版本、成员数量及仓库／包内 README 哈希。
- `SHA256SUMS-v0.11.0.txt`：ZIP 与来源清单的 SHA256。

解压后将 `transcriptomics-figure-workbench` 文件夹安装至自己选择的 skills 目录，或在该文件夹中按 README 使用独立 Python 命令。更新时保护私有主题、画像、额外脚本与项目结果。

## 从精确源码重建

在干净且已提交的本版源码检出中运行：

```sh
python tools/build_release.py --current-only --output dist/current-release
```

构建器仅选择 Git 已跟踪的公开 skill 文件，拒绝私有目录、符号链接和覆盖现有输出。它按流验证每个 ZIP 成员与准确源码的 SHA256，检查包内 README 链接，生成来源清单与下载校验和。相同内容的 ZIP 压缩字节可能因文件时间或工具版本不同而变化；不宣称逐字节可复现。

GitHub 自动验收包含三平台契约、渲染／浏览器检查及包路径／私有文件排除检查。发布前以同一精确提交的实际验收状态为准；提交、打包与上传完成是不同状态。

## 验收含义
