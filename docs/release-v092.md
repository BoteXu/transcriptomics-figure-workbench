# v0.9.2 · 逐类设计检索、富集与亚群证据版式修订

## 本轮内容

- 90个现有基础图型逐项检索，优先2025–2026年；单独记录7篇论文、8张实际看过的原图，按信息组织与可读性选择设计。
- 公开逐项选择、借鉴与舍弃说明；29个图型有相关的原图设计来源。候选搜索不冒充逐图核实，也不因为期刊名就自动采用。
- ORA/跨对比富集与成员证据共享通路行、完整标签、分开的NES/FDR/基因效应语义；纵向阅读版修复色标和标题空间。
- 注释总览按marker归属分块；逐亚群默认先看定位与特异性，再连续展示多个marker，保留完整背景、坐标与共同表达尺度。
- 27个最终PNG逐张屏幕复看；23个已有示例沿用相同冻结输入，4个明确虚构的marker数量样例检查2/4/8/12-marker及自定义布局。
- 修复面板宽度不生效；重新渲染的15份默认图像像素一致，另看过两份加宽布局。保留修订前图、旧版本快照与保护式安装同步。

## 范围

不复制出版商图片、第三方代码或模型，不为美化重拟合统计、嵌入、集合或区间。科研分析继续使用服务器。屏幕自检、软件检查、纸面校样和科学有效性分别记录；本轮不是90种图全部改写或普遍美观认可。新数据和新布局仍需新审阅。
