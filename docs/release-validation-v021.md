# v0.2.1 validation scope

The primary directory is generated from references/drawing-methods.json: 68 drawing families and 24 composition entries. Fifteen cards, three public-coordinate structure examples and one supporting table are separate library entries. The complete archive retains 244 stable source IDs, including all 40 saved compositions; 32 auxiliary component bundles are independently accessible.

The before-update baseline contains the exact PNG/PDF hashes of the prior 236 sources. tests/check_package.py verifies these against actual files, in addition to the 168-source initial-release baseline. No previous preview pixels or supplied intervals were edited to make them appear consolidated. The primary UI and overview use unique family representatives rather than displaying their archived parameter variations again.

New bounded software fixtures cover 14 saved panels: explicit member–term links, triangle cells, frozen trees, additive stacks and supporting coordinates/networks/matrices. Runtime checks exercise invalid values/relationships, saved-table replay and palette/font changes without changing data geometry. Cross-panel checks cover membership/count/ratio, term scores, an exact induced network subset, hierarchy records, leaves, modules, matrix axes and scoring identities. These tests do not estimate correlations, p-values, clusters, enrichment, TOM or binding affinity.

K37–K40 are vector compositions of individually exported bundles with saved layouts and table hashes. The component replay entry point accepts all 32 registered components; the original component adapter paths remain intact.

The primary overview has 10 pages and the full 244-source archive has 21 pages. The gallery keeps the original browser note key and old ID links; the source selector is opt-in and mode choices do not produce duplicate primary cards. All 15 palette entries remain visible under the palette filter.

Completed check results are recorded in [publication-check-v021.json](publication-check-v021.json). CI repeats the static checks, card checks, prior 52-fixture plotting suite and new 14-fixture suite on the exact published commit. Cross-platform fonts, R execution, native renderers and real research analyses are outside this update's validation scope. Installation and hashes cannot establish scientific validity.
