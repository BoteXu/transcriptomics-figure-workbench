- Add per-method discovery with 143 concrete display views. Counts include companion/layout extensions and are not independent algorithms.
- Preserve existing private profiles during public-payload synchronization. Test that public placeholders cannot overwrite protected private profiles; customized code needs explicit protection and review.

## What was checked

Actual synthetic PNG exports were screen-inspected with dense/flagged views enlarged. Selected dense/current PDF files were raster-read separately. Strict input gates, source bindings, export hashes, physical font measurements and offline browser controls have separate checks. Changed layouts require new inspection.

Screen inspection is not blanket aesthetic approval, journal acceptance, an independent review or calibrated paper proof. These fixtures test software/drawing only; no real transcriptomic inference backend was run. The historical v0.9.0 library and its original review scope remain available.

Only public/synthetic examples and generic installation code are included. Private configuration, clinical/research inputs, libraries, credentials, hosts and runtime artifacts are excluded.
