# v0.14.0 — complete transcriptomic alternatives

This increment improves static single figures and compositions in five
families: PCA, volcano, GSEA, raincloud and per-subgroup multi-marker evidence.
The old APIs and historical forms remain available.

See [exact calls, inputs, alternatives and source attribution](../skills/transcriptomics-figure-workbench/references/transcriptomic-alternatives-v0140.md)
and [actual frozen examples](../skills/transcriptomics-figure-workbench/assets/transcriptomic-alternatives/index.html).

The 28 examples include small/medium/large PCA scopes, both volcano forms,
single and multiple GSEA cards plus aligned tracks, horizontal/vertical donor
rainclouds, each of five subgroups in both marker compositions, and 2/4/8-marker
custom layouts. They reuse public fictional result inputs and never refit
scientific results. New geometry/layout changes require fresh visual review.

Current source and tag acceptance, source-bound package identity and checksums
are attached to the release. Rendering, screen self-review, final print proof,
independent review and scientific acceptance are separate states. No private
profile, research data, host, address, client configuration or receipt belongs
in this public package.
