# v0.2.4 validation scope

This release adds fourteen independent result modes (E38–E51) and two saved
compositions (K41–K42). It retains all 244 earlier PNG/PDF source hashes and all
previous scripts. The resulting catalog has 260 sources, 72 drawing families,
26 composition entries, 15 color cards and 42 actual compositions. All 42
compositions have complete horizontal and vertical alternatives. Similar matrix,
curve, stem and calibration modes reuse their existing drawing entry.

The new analysis-result routes cover splice coverage/junctions/isoforms,
variant posterior probabilities, calibration support, decision curves,
regulator activity, pathway overlap, network parameter sensitivity, trajectory
blocks and additive contributions. Additional Biomni-discovered result views
cover symbol heights, physical-bin contact tracks, branch lengths, registered
slice labels and checkerboard/difference images. These renderers read frozen
results. No upstream analysis engine, scientific estimation or external-data
upload is performed.

The full [Python function audit](plot-logic-audit-v024.json) exercised all 108
functions, both page orientations, immutable inputs and quantitative geometry.
No function was uncovered or failed. Its final bounded fixtures had no reported
tick or heading overlap. It retains 502 small-font advisories across the older
complex fixtures; these are reminders for final-size inspection, not silently
suppressed warnings or a claim of universal aesthetic acceptance.

Independent tests check numerical channels and invalid contracts: seven-stage
flows in both directions; zero weights and conserved band quantities; exact
matrix/annotation/count centers; common-axis PDF geometry; five new Biomni views;
nine analysis-result views; their TSV replay and theme replacement. Five guide
regressions retain complete labels, reject heading/tick overlap, preserve
quantitative geometry and check layout optimization is stable when repeated.
The previous 52-case incremental and 14-case linked suites, flexible matrix
inputs, 15 color-card contracts, skill format, Python compilation and publication
structure/privacy/link/hash checks also pass in the local environment.
The core export regression also passes eighteen rejection cases, source/input
hash checks, failed-export retry, existing-output preservation and Unicode
paths/fonts. The [local check manifest](local-release-checks-v024.json) records
the public source hashes without including private runtime receipts.

Manual inspection covered the new sixteen previews, selected updated historical
previews, and selected alternative compositions. The browser opens the module
page, resolves K42's independent panels and input tables, exposes both layouts,
and switches existing matrix families to E47/E49. Manual sampling and bounding
boxes do not establish every possible label density or every target device.

All saved drawing scripts, data contracts and combination recipes are included.
The 28 historical R counterparts remain a separate inventory; complete parity
with new Python views and native protein backends is not implied. Biomni
specialist calls used for discovery returned planning information; cached
runtime status and historical execution success were not treated as current
upstream acceptance. Private profiles, references, data and runtime receipts
remain outside the public package.
