# v0.3 architecture and acceptance

This release reorganizes the existing scientific figure skill around one typed figure specification. Existing Python/R functions, stable examples, compositions and private project profiles remain compatible.

| Layer | Responsibility | Acceptance |
|---|---|---|
| Registry | Derive callable inventory, signatures, examples and dependency groups from shipped source | No plotting imports for discovery; every existing plot function accounted for |
| Contract and plan | Bind one selected table, provenance, renderer, theme and exact source versions | Unknown keys, changed inputs, unsafe paths and incomplete context fail before rendering |
| Rendering | Load the selected fixed callable; reuse established frozen-table implementations | Exact table preservation, real output files and no automatic dependency installation |
| Appearance | Shared category identities plus named typography and spacing profiles | Restyling preserves quantitative geometry and source bindings |
| Studio | Browse the complete catalog, compare examples, edit a selected SVG locally and export redraw settings | No network requests, uploads or executable imported SVG; preview edits remain distinct from final exports |
| Review | Verify files and record hash-bound visual decisions | Modified exports invalidate acceptance; software, visual and scientific acceptance stay distinct |

New fixed routes expose existing raincloud, volcano, paired, supplied curve and rank views through the same contract. Plot families, callable functions, presets, examples and compositions are counted separately. No upstream analysis engine is added.

The installable skill contains the workflow and Studio builder. The repository also contains the complete historical gallery. Private data, profiles, machine paths and runtime logs are excluded from the public package. Host-specific execution restrictions still apply.
