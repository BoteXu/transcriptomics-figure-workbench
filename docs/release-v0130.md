# v0.13.0 · 可选画法、可读性与稳定导出

在 SciSpace 检索及原始来源复核后，继续优化现有联动检查器。

- 同一冻结结果可选普通散点、少量对象的标签散点、带给定区间的点线图。三种显示方式复用同一身份与输入，不计为新科学算法。
- 修复长轴标题、长标签与窄面板的换行和留白；列数根据实际宽度调整。
- 给分组增加固定形状、名称过滤按钮和输入计数，选中对象置于前层。
- 每面板一个 Tab 停靠点，方向键浏览、Home/End 跳转、Enter/Space 选择，保留寄存表。
- SVG 按请求尺寸重新绘制，窄屏查看不会改变导出几何；保留缺失数量、区间含义和上下文。寄存表保留完整数值精度。
- 实际示例增加六分组长标签／缺失值、12 对象全标签，以及六效应给定区间；原有四例、42 配方、三维、体渲染、轨迹动画及所有历史画法保留。
